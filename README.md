# Engenheiro Racing — instaladores

Engenheiro de corrida por voz para o Assetto Corsa Competizione.

Aqui ficam só os instaladores. Baixe o mais novo em **[Releases](../../releases/latest)** (`EngenheiroRacing-Setup-<versão>.exe`).

- O Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**.
- Depois de instalado, o app avisa sozinho quando tiver versão nova.
